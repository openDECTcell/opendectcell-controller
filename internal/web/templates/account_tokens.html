Make a token

A token lets a script, a widget or another program use your account through the API without your password. It can do only what you tick, only until it expires, and you can revoke it any time. Tick as little as the program needs. At most {{.Max}} tokens at a time.

What a token cannot do

  • Anything of the administrators' side, enrolling base stations, organizations, or making tokens: those need you at the browser.
  • Read a VoIP line's password, or a handset's key.
  • Reach the web pages: it works on /api/v1 only.

The API is described in docs/api/openapi.yaml.
