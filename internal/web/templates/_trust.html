Whoever runs a base station can read your handset's key

A DECT base station can serve a handset only if it holds the handset's secret key. The person who has administrator access to that box can read the key, listen to the calls that pass through it, and see the numbers dialled and who calls. This is how DECT is built. This software cannot change it, and the encryption between the box and this controller does not help, because the box itself is the other end.

A key that has been read stays useful until the handset is registered again; removing a base station from the controller does not take it back. So let your handsets use only base stations whose operators you trust.
