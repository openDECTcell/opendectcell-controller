{{icon "antenna-bars-5"}} Roaming

Every handset can connect to every cell. A cell holds a handset in memory only while it is around: it is taken from the database when it first talks to the cell, and dropped when it stops renewing.

Rounded to 40.96 s; at most 10445; 0 does not ask them to. Each renewal costs the handset a short radio link, so battery. The chips keep hearing an idle handset for at least an hour, so this only sets how soon a handset that left or was switched off is noticed; a longer interval saves battery.
