This replaces the identity of a running system

The system identity is {{.Current.String}}. Handsets registered under it know the cells by that identity. If the cells use it, every handset on every cell stops finding its base and has to register again, one by one. Do this only for a fresh start.

Before you save it

    {{if eq .Proposed.Source "random"}}
  • This EIC is made up. ETSI allocates EICs (EN 300 175-6 §5.2) and publishes no list of the allocated ones, so it cannot be checked: it may belong to a real DECT system.
  • If a system with the same identity is within radio range, its handsets and ours may try each other's bases. Registration and calls can then fail on either side.
  • A made-up EIC does not conform to EN 300 175-6. Use it for experiments; an allocated one comes from ETSI's codes service.
    • {{else}}
  • Use only an EIC ETSI allocated to you, and an FPN and FPS of yours under it: the same identity on two systems within radio range lets handsets try each other's bases.
    • {{end}}
  • Changing the identity later, once cells use it, means every handset must register again.
