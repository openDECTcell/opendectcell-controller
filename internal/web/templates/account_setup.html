{{icon "download"}} Export my setup

One file with your handsets, VoIP lines and contacts, to move them to another controller or to have them again after a loss. What you export, only you can import: into your own account, here or on another controller.

With keys, a handset can be brought over without registering it again, and the lines work at once. Whoever holds the file and its passphrase can use your handsets' identities and your VoIP accounts: keep the file as you would keep a password. The file is encrypted with the passphrase below; nobody can recover it for you, and this controller never stores it. Without keys, the file only carries settings and is not encrypted.

{{icon "upload"}} Import a setup

Choose a setup file. Check the file shows what would happen without changing anything; Import does it. Lines you have already (the same user name and domain) and contacts you have already are left as they are. A handset of the file that you have already gets the file's settings. A handset whose identity is registered on this controller by anyone is never taken over.

VoIP lines from a spreadsheet

Many lines at once, from a CSV file (Excel and LibreOffice can write one). Start from the template: one row per line, with at least the user name and the domain. The passwords in the file stay in your file: they are not kept or shown. The same check comes first.

What moves, and what does not

  • A handset that comes over with its key does not need to be registered again: the first base station that hears it takes it in. Whether it then works on air is something the handset decides; try it before you delete the old one.
  • Address books, call history, shared lines and base stations are not in the file.
  • A VoIP line without its password is imported without one: enter it on the line's page.
  • The file is for you: another user who imports it gets copies in their own account, never yours.
